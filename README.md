# גררילה · מחשבון גרירה

אפליקציה לטלפון של מתן: מכניסים איסוף ויעד בזמן השיחה ומקבלים מחיר מוכן להגיד ללקוח.

- `src/app.html`: הקוד של האפליקציה
- `src/places.js`: רשימת היישובים והקואורדינטות
- `python3 build.py`: בונה את `docs/` (אפליקציה עצמאית שאפשר להתקין על המסך הראשי, עובדת גם בלי אינטרנט)

## נוסחת המחיר (ניתנת לשינוי במסך "תעריפים")
סבב = בסיס ← איסוף + איסוף ← יעד + יעד ← בסיס
מחיר = 249 ₪ (כולל 20 ק״מ) + 4.5 ₪ לק״מ עד 80 ק״מ + 3.5 ₪ לק״מ מעבר לזה, ועוד תוספות. מעוגל כלפי מעלה לסכום שמסתיים ב־9. כולל מע״מ.
